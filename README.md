## ▶️ How to Run a Project

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/java-projects.git
   ```

2. Navigate to a project:

   ```bash
   cd java-projects/Project-1
   ```

3. Compile the program:

   ```bash
   javac Main.java
   ```

4. Run the program:

   ```bash
   java Main
   ```
